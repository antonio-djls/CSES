# CSES Soluções

![CSES](cses.png)

Este repositório armazena as soluções dos problemas encontrados no CSES (Competitive Programming Problem Set).

## Objetivo

O objetivo principal é estudar algoritmos e estruturas de dados através da prática de resolução de problemas de programação competitiva.

## Estrutura

Cada diretório corresponde a uma seção do CSES, contendo as soluções implementadas em C++.

## Conteúdo

- Problemas resolvidos com explicações
- Análise de complexidade
- Diferentes abordagens de solução
